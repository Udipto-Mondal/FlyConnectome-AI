> **NeuroGraph AI** is an autonomous, research-oriented agentic scientific platform designed to convert natural-language neuroscience questions into evidence-grounded neural circuit discoveries.
>
> The system grounds multi-agent reasoning in the official **Drosophila melanogaster Male Central Nervous System (Male CNS v1.0)** connectome dataset, combining Graph-RAG, graph algorithms, peer-reviewed literature validation via Europe PMC, and in-silico circuit ablation.

## 🔬 Scientific Data Source & Ground Truth

The canonical source of truth for neural connectivity is the **Drosophila Male CNS connectome dataset (v1.0)** released by Janelia Research Campus and Google Research:
- **Scope**: Reconstructed full central brain and ventral nerve cord (VNC).
- **Volume**: 160,000+ reconstructed neurons, 120,000,000+ verified chemical synapses.
- **Interface**: Official neuPrint API (`https://neuprint.janelia.org`) and `neuprint-python`.

> [!IMPORTANT]
> **Scientific Integrity & Evidence Standard**:
> - The LLM is **never** the source of truth for neural connectivity.
> - Neural connections, neuron types, and synapse counts are directly retrieved from the real connectome dataset.
> - Synthetic graph stubs are strictly isolated as local development fixtures (`backend/app/graph/connectome_data.py`) and never presented as biological evidence.

## 🏛️ Tripartite Evidence Separation

All findings generated by NeuroGraph AI are partitioned into three immutable tiers:

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                       TRIPARTITE EVIDENCE CATEGORIES                        │
├───────────────────────┬─────────────────────────────┬───────────────────────┤
│  CONNECTOME EVIDENCE  │     LITERATURE EVIDENCE     │ COMPUTATIONAL INFERENCE│
│       (Tier A)        │          (Tier B)           │       (Tier C)        │
├───────────────────────┼─────────────────────────────┼───────────────────────┤
│ • Neuron Body IDs     │ • Peer-reviewed papers      │ • Dijkstra paths      │
│ • Synapse counts      │ • Author & journal metadata │ • Flow centrality     │
│ • Neuropil ROIs       │ • Resolvable DOI / PMID     │ • In-silico ablation  │
│ • Verified morphology │ • Experimental findings     │ • Network metrics     │
└───────────────────────┴─────────────────────────────┴───────────────────────┘
```

If connectome data does not support a hypothesized pathway, the system explicitly reports:
> *"Insufficient connectome evidence was retrieved for this claim."*

## ⚡ Quick Start & Development Setup

### Prerequisites
- Python 3.12+
- Node.js 20+ (for frontend development)
- Git

### 1. Backend Setup

```bash
# Clone repository
git clone https://github.com/Udipto-Mondal/NeuroGraph-AI.git
cd NeuroGraph-AI

# Create virtual environment
python -m venv .venv

# Activate virtual environment (Windows PowerShell)
.venv\Scripts\Activate.ps1
# (Linux/macOS: source .venv/bin/activate)

# Install dependencies
pip install -r backend/requirements.txt

# Copy environment configuration
cp .env.example .env
```

### 2. Run Automated Tests

```bash
# Run pytest test suite
pytest
```

### 3. Launch FastAPI Development Server

```bash
uvicorn app.main:app --app-dir backend --host 0.0.0.0 --port 8000 --reload
```

Access API documentation at: **`http://localhost:8000/docs`**  
Access System Health at: **`http://localhost:8000/api/health`**  
Access Architectural Info at: **`http://localhost:8000/api/info`**
